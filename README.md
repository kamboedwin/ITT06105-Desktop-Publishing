# ITT06105 — Desktop Publishing

**Ordinary Diploma in Information Technology · Academic Year 2026/2027**

This site provides ten lectures covering desktop publishing concepts, graphics and typography, document planning, basic image editing, vector artwork, page layout, printing and image compression.

Each lecture contains reading notes, illustrations, presentation slides, a guided practical activity, review questions and a self-marking practice quiz. Quizzes provide immediate feedback and explanations for incorrect or unanswered questions. They are for revision and do not submit grades.

The Tumaini Community Learning Centre examples are fictional and are used to practise preparing a simple educational hand-out.

Start at **index.html** or select any lecture from the course overview. Your marked-as-studied progress is stored only on the device and browser you use.
